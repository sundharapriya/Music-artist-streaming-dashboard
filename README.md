# Music Artist Streaming Dashboard

An interactive **Power BI dashboard** for analyzing music artist streaming data.

##  Features

- Total Artists, Streams, Average Streams & Countries
- Top 10 Artists by Streams
- Streams by Genre
- Streams by Artist Type
- Streaming Trends by Debut Year
- Interactive Filters

##  Tools

**Power BI | Power Query | DAX | Data Visualization**

##  Objective

To transform music streaming data into meaningful insights through an interactive and visually appealing dashboard.
